# _projeto

**Nada aqui ensina SAP IS-U.** Esta pasta guarda o que é sobre o repositório,
não sobre o assunto dele.

A separação existe porque as duas coisas competem. Documentação de processo
misturada com conteúdo de estudo faz o leitor gastar atenção decidindo o que é
matéria e o que é bastidor, e faz uma busca no acervo trazer regra de escrita
quando você procurava por transação.

**A raiz e a pasta [`notas/`](../notas/) ficam só com o assunto. O resto mora
aqui.**

## O que está aqui

| Arquivo | O que é | Quando abrir |
|---|---|---|
| [`PADRAO.md`](PADRAO.md) | O esqueleto de uma nota: as sete zonas obrigatórias, as cinco formas de pista, a regra da seção vazia | Antes de escrever ou revisar uma nota |
| [`EM-ABERTO.md`](EM-ABERTO.md) | O que o material nomeia e nunca explica, e quem pode fechar cada lacuna | Ao processar uma aula nova, ou ao preparar pergunta para o instrutor |
| [`AUDITORIA-NOTEBOOKLM.md`](AUDITORIA-NOTEBOOKLM.md) | Diagnóstico de 23/08/2026 sobre o que degrada quando o acervo vira fonte de um modelo, e o que foi corrigido | Antes de subir o acervo em qualquer ferramenta de recuperação |
| [`PREPARACAO.md`](PREPARACAO.md) | O que costuma ser cobrado, os tipos de exercício prático e o que se resolve sozinho contra o que se escala. **Expectativa, não fonte** | Ao planejar a revisão, e para levar as dúvidas ao instrutor |

## O que não está aqui

- **`.github/CONTRIBUTING.md`** mora em `.github/` porque o GitHub lê aquele
  caminho nativamente e mostra o link de contribuição a partir dele
- **`.github/ISSUE_TEMPLATE/`** precisa ficar na raiz do repositório. Movida, a
  pasta deixa de existir para o GitHub e os templates de issue morrem
- **`ferramentas/`** é código, e código não é documentação de processo

## A regra

**Arquivo que fala do repositório vem para cá. Arquivo que fala de IS-U fica
fora.** Em dúvida, pergunte se um consultor que nunca viu este repositório
ganharia algo lendo. Se não ganhar, o lugar é aqui.
